# Store assets

Generated by `python scripts/make-store-assets.py` from `store/source-logo.png`.

| File | Size | Purpose | Goes to |
|---|---|---|---|
| `source-logo.png` | 442x432 RGBA | Original logo master (input) | Script input only |
| `../assets/icon.png` | 1024x1024 RGB | App icon, black background | App (`app.json` icon) |
| `../assets/adaptive-icon.png` | 1024x1024 RGBA | Android adaptive foreground (tile in 620px safe zone) | App (adaptiveIcon, background `#000000`) |
| `../assets/notification-icon.png` | 96x96 RGBA | White monochrome "F" status-bar icon | App (expo-notifications plugin) |
| `play-icon-512.png` | 512x512 PNG | Hi-res icon | Play Console: Store listing, App icon |
| `feature-graphic-1024x500.png` | 1024x500 RGB, no alpha | Feature graphic | Play Console: Store listing, Feature graphic |

For crisper icons, replace `store/source-logo.png` with a 1024×1024 master and rerun the script.

## Switching logo concepts

The logo is drawn from geometry by `scripts/make-store-assets.py` (no image source needed).

- `python scripts/make-store-assets.py --sheet` writes `store/logo-concepts.png` (compare A, B, C).
- `python scripts/make-store-assets.py --concept B` regenerates every icon and graphic for that concept (A is the default) and writes `store/logo-<concept>.svg`.
- Then set `app.json` `android.adaptiveIcon.backgroundColor`: A `#3B4FD8`, B `#172554`, C `#1592DD`.
